## 下一步 1️⃣：开启 Socket Mode + 拿 `xapp-...`

左侧菜单：

**Settings → Socket Mode**

1. 打开 **Enable Socket Mode**
2. Slack 会提示你创建 **App-Level Token**
3. 创建时：

   * Token name：随便
   * **Scope：只选 `connections:write`**
4. 创建完成后，复制得到：

   ```
   xapp-xxxxxxxx
   ```

👉 这是 **SLACK_APP_TOKEN**（非常关键）

---

## 下一步 2️⃣：安装 App，拿 `xoxb-...`

左侧菜单：

**OAuth & Permissions**

1. 确认下方 **Bot Token Scopes** 已经有（你用的是完整版 manifest，已经齐了）
2. 点击顶部按钮：
   **Install App to Workspace**
3. 授权完成后，你会看到：

   ```
   Bot User OAuth Token
   xoxb-xxxxxxxx
   ```

👉 这是 **SLACK_BOT_TOKEN**（同样关键）

---

## 下一步 3️⃣：回到你本机，设置环境变量

如果你在 **Windows PowerShell**：

```powershell
setx SLACK_APP_TOKEN "xapp-你的token"
setx SLACK_BOT_TOKEN "xoxb-你的token"
```

> ⚠️ 注意：`setx` 后要 **新开一个终端窗口** 才会生效
